# ネットワークスペシャリスト 午後CBTシミュレータ (H24〜R06)

平成24年度（H24）〜令和6年度（R06）のネットワークスペシャリスト試験（午後Ⅰ・午後Ⅱ、全12年度・60問・682設問・図表画像329枚）を収録したスタンドアロンCBT演習Webアプリケーションです。

## 起動方法

### 方法1：ブラウザで直接開く（サーバ不要）
`cbt_data` フォルダ内の **`index.html`** をダブルクリックしてブラウザ（Chrome / Safari / Edge / Firefox）でそのまま開いてください。
- `js/index.js` および `js/<年度>.js` をオンデマンドで動的ロードする仕組みのため、`file://` プロトコルでもCORSエラーなしで高速に動作します。

### 方法2：ローカルWebサーバで起動する
`cbt_data` フォルダ内の **`start_server.command`** をダブルクリックすると、ローカルHTTPサーバ（`http://localhost:8765`）が起動し、既定のブラウザで自動的に開きます。

## 主な機能

- **2つの出題モード**
  - **演習モード**：1問・1設問ごとにすぐ解答・解説を確認可能。
  - **本番試験モード**：午後Ⅰ（90分・3問中2問選択）、午後Ⅱ（120分・2問中1問選択）の制限時間カウントダウンタイマーと一括採点機能を搭載。
- **左右2ペインCBT画面 & 補助ツール**
  - **左ペイン**：問題本文と高解像度図表のインライン表示、図表のフローティング固定（ピン留め）・拡大ズーム表示、3色蛍光ペン（マーカー）機能（`localStorage` に自動保存）。
  - **右ペイン**：設問ナビゲーション、リアルタイム文字数カウンタ（字数制限超過アラート付き）、記述式の必須キーワード含有チェッカー、模範解答・詳細解説表示。
- **ハイブリッド採点方式**
  - **短答・穴埋め（`fill_in_blank` / `short_answer`）**：解答の表記ゆれ（全角/半角・スペース等）を正規化して自動一致判定（手動での上書きも可能）。
  - **記述式（`descriptive`）**：模範解答・必須キーワードを並べて比較し、ワンクリックで **○ 正解 (100%) / △ 部分点 (50%) / × 不正解 (0%)** を自己採点。
- **学習履歴 & ブックマーク保存**
  - 設問ごとの正誤履歴・解答テキスト・復習チェック（★ブックマーク）をブラウザに自動保存。
  - 画面右上の「履歴書出 / 読込」からJSONファイルとしてバックアップ・復元が可能。

## ディレクトリ構成

- `index.html` : アプリ本体HTML
- `styles.css` : スタイルシート（ライト / ダークテーマ対応）
- `app.js` : シミュレータ制御スクリプト
- `start_server.command` : macOS用ローカルサーバ起動スクリプト
- `index.json` / `H24.json`〜`R06.json` : 年度別構造化データ（JSON形式）
- `js/index.js` / `js/H24.js`〜`js/R06.js` : `file://` 直接起動用のオンデマンドJSバンドル
- `images/H24/`〜`images/R06/` : 切り出し済みの図表・ネットワーク構成図PNG画像（全329枚）
